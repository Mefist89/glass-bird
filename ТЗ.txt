Техническое задание (ТЗ) на разработку платформы «glassbird»
1. Общее описание проекта
Название: glassbird
Цель: Создание современной, быстрой и удобной веб-платформы для обучения студентов.
Контент: На старте платформа включает три основных курса:

Программирование на Python.

Компьютерные сети.

Базы данных.

2. Технологический стек
Frontend/Backend: Next.js (App Router).

База данных и Авторизация: Supabase (PostgreSQL, Supabase Auth).

Стилизация: Tailwind CSS.

UI-компоненты: shadcn/ui (Радикс-примитивы, иконки Lucide).

Видеохостинг: YouTube (встраивание через iframe, доступ к видео только по ссылке).

3. Роли пользователей
Гость (Аноним): Может просматривать главную страницу (Landing), читать описания курсов, видеть программу обучения.

Студент (Авторизованный): Имеет личный кабинет, доступ к видеоурокам, может отмечать пройденные материалы, видит свой прогресс.

Администратор: Имеет доступ к панели управления Supabase для прямого редактирования базы данных (добавление уроков, управление пользователями). На первом этапе отдельная админка на самом сайте не требуется, все управляется через интерфейс Supabase.

4. Основной функционал (MVP — минимально жизнеспособный продукт)
4.1. Главная страница (Landing Page)

Hero-блок с названием "glassbird", призывом к действию и абстрактной IT-иллюстрацией.

Секция с тремя карточками курсов (Python, Сети, БД).

Футер.

4.2. Система авторизации

Регистрация и Вход (Email/Пароль или магия Google OAuth через Supabase).

Восстановление пароля.

4.3. Личный кабинет студента (Dashboard)

Отображение доступных курсов.

Прогресс-бар по каждому начатому курсу (например, "Пройдено 4 из 12 уроков — 33%").

4.4. Страница курса и видеоплеер

Боковая панель (Sidebar) со списком модулей и уроков курса.

Основная область: встроенный плеер YouTube.

Текстовое описание под видео (конспекты, полезные ссылки, сниппеты кода для Python/SQL).

Кнопка "Завершить урок" (отправляет Server Action в Supabase для записи прогресса и открывает следующий урок).

5. Требования к дизайну (UI/UX)
Тема: По умолчанию Dark Mode (темно-синие и глубокие навигационные оттенки).

Стиль: Элементы Glassmorphism (полупрозрачные карточки с размытием фона), чистая типографика, минимализм.

Компоненты: Использование shadcn/ui для кнопок, карточек (Cards), навигационного меню, диалоговых окон и уведомлений (Toasts).

Адаптивность: Полная поддержка мобильных устройств (Tailwind).
